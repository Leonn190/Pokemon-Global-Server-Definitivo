# Como contribuir

Obrigado pelo interesse no **Pokémon Global Server**.

Este repositório público existe principalmente para apresentação, consulta, estudo técnico e acompanhamento do desenvolvimento do projeto. O código-fonte do jogo **não deve ser modificado diretamente por terceiros**.

## Política de contribuição

No momento, contribuições externas modificando o jogo, o código-fonte, os dados oficiais, os sistemas internos, os recursos visuais ou a estrutura do repositório **não são aceitas**.

Isso significa que não devem ser enviados Pull Requests alterando:

- código principal do jogo;
- sistemas de batalha, mundo, servidor, site ou ferramentas internas;
- tabelas, regras, configurações e dados oficiais;
- assets, sprites, imagens, áudio ou outros recursos;
- estrutura de pastas, organização interna ou arquivos de build;
- documentação oficial do projeto sem autorização.

Também não devem ser feitas tentativas de modificar, redistribuir ou substituir partes do projeto por versões alteradas.

## Por que o repositório não aceita modificações externas diretas?

O Pokémon Global Server possui uma estrutura própria de desenvolvimento, balanceamento, organização de dados, sistemas internos e controle de versões.

Para proteger a integridade do projeto, evitar alterações indevidas e manter controle sobre a versão oficial do jogo, o código disponibilizado publicamente pode ser protegido, ofuscado, criptografado ou publicado apenas em formato adequado para consulta e apresentação.

A existência do repositório público não significa autorização para alterar, clonar, republicar ou criar versões modificadas do jogo oficial.

## Mods da comunidade

No futuro, o Pokémon Global Server pretende oferecer suporte adequado para **mods da comunidade**.

A ideia é que jogadores e criadores possam desenvolver conteúdos personalizados de maneira organizada, segura e compatível com o jogo, sem precisar modificar o código-fonte oficial do projeto.

Esse suporte poderá incluir, futuramente:

- estrutura própria para mods;
- regras claras de compatibilidade;
- documentação para criação de conteúdo;
- separação entre conteúdo oficial e conteúdo da comunidade;
- formas seguras de carregar, ativar e desativar mods;
- ferramentas ou padrões específicos para criação de modificações.

Quando esse sistema estiver disponível, as contribuições da comunidade deverão acontecer por meio dos mecanismos oficiais de modding, e não por alterações diretas no repositório principal.

## Issues e Pull Requests

Não utilize Issues ou Pull Requests deste repositório para tentar alterar o projeto oficial.

Caso queira relatar um problema, sugerir algo ou entrar em contato com a equipe, utilize os canais oficiais indicados pelo projeto, especialmente o site oficial do Pokémon Global Server.

## Conduta esperada

Ao interagir com o projeto, espera-se que todos mantenham uma postura respeitosa, responsável e honesta.

Não é permitido:

- tentar se passar por membro oficial do projeto;
- redistribuir versões modificadas como se fossem oficiais;
- remover créditos;
- divulgar builds alteradas sem autorização;
- explorar falhas do projeto;
- usar o nome Pokémon Global Server para enganar usuários;
- publicar conteúdo ofensivo, abusivo, ilegal ou prejudicial associado ao projeto.

## Uso permitido

É permitido:

- visualizar o repositório;
- estudar a organização geral do projeto;
- acompanhar o desenvolvimento;
- usar o projeto como referência de portfólio e estudo, sem cópia substancial;
- entrar em contato por canais oficiais para relatar problemas ou apresentar sugestões.

## Aviso de projeto fan-made

Pokémon Global Server é um projeto fan-made, não oficial, criado para fins de estudo, desenvolvimento pessoal, portfólio e entretenimento.

Este projeto não possui afiliação, patrocínio, aprovação ou vínculo oficial com Nintendo, Game Freak, Creatures Inc. ou The Pokémon Company.

# Política de Segurança

A segurança e a integridade do **Pokémon Global Server** são importantes para o projeto.

Este repositório público não deve ser usado para abrir Issues, Pull Requests ou alterações relacionadas a bugs, falhas, vulnerabilidades ou modificações do jogo.

## Forma oficial de reportar bugs

A forma oficial de reportar bugs, falhas ou problemas do Pokémon Global Server é acessar o **site oficial do Pokémon Global Server** e tentar entrar em contato com a justificativa de **reportar bugs**.

Ao entrar em contato, explique com clareza que o objetivo é relatar um problema encontrado no jogo, no site ou em algum sistema relacionado ao projeto.

## O que incluir no reporte

Ao reportar um bug ou possível falha, inclua, se possível:

- descrição clara do problema;
- passos para reproduzir o erro;
- o que você esperava que acontecesse;
- o que aconteceu de fato;
- prints, vídeos ou logs, se forem úteis;
- versão do jogo, quando aplicável;
- sistema operacional, quando o problema estiver relacionado à execução local;
- qualquer informação relevante sobre o contexto em que o erro ocorreu.

## Vulnerabilidades e problemas graves

Caso o problema envolva segurança, abuso, exploração, alteração indevida, corrupção de dados ou qualquer risco para outros jogadores, não divulgue publicamente os detalhes.

Entre em contato pelos canais oficiais do projeto e informe que o caso pode envolver uma falha de segurança.

Exemplos de problemas graves:

- exposição de dados sensíveis;
- falhas que permitam acesso indevido;
- exploração de sistemas online;
- manipulação indevida de progresso, saves ou dados;
- execução de código não autorizado;
- formas de burlar sistemas do jogo;
- falhas que possam afetar outros jogadores.

## O que não fazer

Não tente reportar bugs ou vulnerabilidades por meio de alterações no repositório.

Não faça:

- abertura de Issues no repositório para reportar bugs;
- Pull Requests tentando corrigir ou modificar o jogo;
- forks com correções não autorizadas;
- divulgação pública de falhas exploráveis;
- publicação de tutoriais ensinando a explorar bugs;
- modificação do código-fonte oficial;
- redistribuição de versões alteradas do projeto.

## Versões suportadas

Como o Pokémon Global Server está em desenvolvimento, apenas a versão oficial mais recente disponibilizada pelos canais do projeto é considerada suportada.

Versões antigas, cópias modificadas, forks, builds alteradas ou redistribuições não autorizadas não recebem suporte oficial.

## Aviso

Esta política existe para proteger o projeto, os jogadores e a versão oficial do Pokémon Global Server.

Pokémon Global Server é um projeto fan-made e não possui afiliação oficial com Nintendo, Game Freak, Creatures Inc. ou The Pokémon Company.
